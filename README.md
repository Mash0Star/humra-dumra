g# humra-dumra
A silly umu-run launcher.

![logo](src/logo.png)

## Requirements
``umu-run`` (Arch Linux package:``umu-launcher``)

## Config
Default file location = ``~/.config/humra-dumra/config.toml``
Default variables = ``proton_path = "~/proton" prefix_path = "~/.pfx"``
